### 00 첫 컴포넌트 — ✅ 보완 후 통과 (2026-09-17)

- 시작: 2026-09-17

#### 1차 리뷰 (2026-09-17, `9bae5b2`) — 보완 요청

- **진행 중 막힌 곳**: `useState`를 컴포넌트 밖(모듈 최상위)에서 호출 → Invalid hook call. prop 이름 불일치 2회(`members`/`member`, `onClick`/`selectMember`). 선택을 "단일 선택"으로 읽고 state를 App에 올리려 했음 → 요구사항 재확인 후 카드 내부 state로 결정.
- **잘한 점**: `key={member.id}`, 삼항으로 배지를 DOM에서 제거, 카드별 state로 독립 토글, className·버튼 글자까지 선택 상태 반영. lint 통과. 자식→부모 콜백에 id를 올리는 패턴을 스스로 찾음(최종 코드에선 불필요해져 제거 — 제거한 판단도 좋음).
- **보완 항목 (통과 조건)**:
  1. `teamRoles` 필터로 PM·QA가 빠져 5명 중 3명만 렌더링됨 (요구사항 2·4)
  2. `useState(members)` — setter를 쓰지 않는 state
  3. 생각해볼 질문 3개 답변 미제출
- **관례 (통과와 무관)**: `let [selected, ...]` → 왜 `const`여야 하는지, 폴더명 `Components` vs 요구된 `components`(대소문자 구분 OS에서 문제), 커밋 메시지에 설명 누락(`feat(00): ...`), `Starter00.jsx`가 포매터로 변경됨(참고용 파일은 그대로 두기), 버튼 글자 `선택해제` vs 스타터 `선택 해제`.
- **나중에**: `setSelected(!selected)` vs 업데이터 함수 형태 — state 단계에서 다룸.
