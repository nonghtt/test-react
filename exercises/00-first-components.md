# 00 · 첫 컴포넌트 (진단)

예상 시간: 30~45분 · 개념: 컴포넌트, props, 리스트 렌더링, 조건부 렌더링, useState 맛보기

이 실습은 현재 수준을 파악하는 용도입니다. 모르는 게 있어도 검색해서 진행하고, 어디서 막혔는지 완료 보고 때 알려주세요.

## 목표

팀원 목록 페이지를 만듭니다. 데이터는 `src/data/members.ts`에 있습니다.

```
┌─ container ──────────────────────────────┐
│  팀원 목록                     총 5명      │
│                                          │
│  ┌ card ────┐ ┌ card ────┐ ┌ card ────┐  │
│  │ (avatar) │ │ (avatar) │ │ (avatar) │  │
│  │ 이름      │ │ 이름      │ │ 이름      │  │
│  │ 역할      │ │ 역할      │ │ 역할      │  │
│  │ [온라인]  │ │          │ │ [온라인]  │  │
│  │ [선택]    │ │ [선택]    │ │ [선택]    │  │
│  └──────────┘ └──────────┘ └──────────┘  │
└──────────────────────────────────────────┘
```

## 요구사항

1. `App.tsx`의 자리표시 내용을 지우고 페이지를 구성합니다.
2. 팀원 한 명을 보여주는 **`MemberCard` 컴포넌트**를 별도 파일로 만듭니다. 이름, 역할, 아바타를 표시합니다.
3. 온라인인 팀원에게만 `온라인` 배지를 보여줍니다. 오프라인이면 배지 자체가 없어야 합니다.
4. 목록 상단에 총 인원 수를 표시합니다. 숫자를 직접 쓰지 말고 데이터에서 계산합니다.
5. 각 카드에 `선택` 버튼을 둡니다. 누르면 그 카드가 선택 상태(`card selected`)가 되고, 버튼 글자는 `선택 해제`로 바뀝니다. 다시 누르면 원래대로 돌아옵니다. **카드마다 독립적으로** 동작해야 합니다.

## 완성 조건

- [ ] `MemberCard`가 별도 파일(`src/components/MemberCard.tsx`)에 있고 props로 데이터를 받는다
- [ ] 목록은 `map`으로 렌더링하고 콘솔에 `key` 관련 경고가 없다
- [ ] 오프라인 팀원 카드에는 배지 엘리먼트가 DOM에 존재하지 않는다 (숨기는 게 아니라 없어야 함)
- [ ] 인원 수가 데이터 길이에서 계산된다
- [ ] 카드 선택이 카드별로 독립적으로 토글된다
- [ ] `npm run lint` 경고 없음, 브라우저 콘솔 에러 없음
- [ ] CSS를 직접 쓰지 않고 `docs/UI.md`의 클래스만 사용했다
